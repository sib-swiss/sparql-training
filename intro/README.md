This directory holds a short, standalone introduction to RDF and linked data - what a triple is, and why bioinformatics resources bother with any of this at all - meant to run *before* [`basic/tutorial.md`](../basic/tutorial.md) for anyone who has never seen a triple before.

It's built around the "I ❤️ ELIXIR" example from Jerven Bolleman's talk *"Bottom up interoperability using semantics in ELIXIR resources"*, given in the ELIXIR track at ECCB (see [`4_Tuesday_1145_Bolleman.pdf`](../4_Tuesday_1145_Bolleman.pdf) in the repository root) - rewritten here as its own page, with a runnable, editable example, rather than as slides.

Read it on the published site, or as plain Markdown in [tutorial.md](./tutorial.md).
