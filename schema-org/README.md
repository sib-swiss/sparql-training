This directory holds a standalone page about [schema.org](https://schema.org/) and [Bioschemas](https://bioschemas.org/) - the general-purpose vocabulary that web pages embed (usually as JSON-LD) so search engines and other tools can understand structured facts about a page, and the life-science profile of it that Bioschemas defines. It's general knowledge, not specific to any one SIB resource, so it lives on its own rather than inside `UniProt/` or `Rhea/`.

It builds on [RDF and linked data](../intro/tutorial.md)'s brief mention of schema.org, and reuses the `P0A877` UniProtKB entry from `UniProt/00_introduction.md` for its worked example.

Read it on the published site, or as plain Markdown in [tutorial.md](./tutorial.md).
